# Data Jobs Dashboard with Power BI

![Dashboard Page 1](/Images/Project1_Page%201.PNG)

## Introduction
This project uses Power BI to explore a dataset of 2024 data science job postings. The dashboard brings together information such as job titles, salaries, locations, and other job details in one place so the data can be filtered and compared more easily.

## Skills Used

- **Data Transformation with Power Query:** Cleaned and prepared the data by handling blank values, changing data types, and creating new columns.
- **Measures and KPIs:** Created measures for values such as `Median Yearly Salary` and `Job Count`.
- **Charts:** Used Column, Bar, Line, and Area charts to compare job counts and identify trends.
- **Geospatial Analysis:** Used Map charts to show the geographic distribution of job postings.
- **KPI Cards and Tables:** Used Cards to highlight key metrics and Tables to display detailed information.
- **Dashboard Design:** Designed the dashboard layout and selected visuals to present the data clearly.
- **Interactive Reporting:**
    - **Slicers:** Used to filter the report by Job Title.
    - **Buttons and Bookmarks:** Used for navigation between report pages.
    - **Drill-Through:** Used to open a detailed view for a selected job title.

## What I Learned

This project helped me practice working with Power Query and Power BI while building an interactive report from raw job-posting data. Specifically, I learned how to clean messy, inconsistent salary data by handling blank values and standardizing data types. I also gained experience selecting suitable visuals, creating summary metrics, and using interactive features like bookmarks and drill-through to make the report easier to explore.
