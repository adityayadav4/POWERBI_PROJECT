
# Power BI Dashboard

This repository contains two Power BI dashboard projects based on data job postings. These projects helped me practise data cleaning, data visualization, data modeling, and building interactive reports using Power BI.

## Projects

### Project 1: Data Jobs Dashboard

![Data Jobs Dashboard](/Images/Project1_Page%201.PNG)

This dashboard explores data job postings, including job titles, salaries, locations, and other job market details. It provides an interactive way to filter and compare information.

**Skills Practised**
- Data cleaning and transformation using Power Query
- Data modeling and table relationships
- Charts, KPI cards, and tables
- Slicers, buttons, and bookmarks
- Drill-through for detailed analysis

[View Project 1 Details](Dashboard_v1\README.md)

### Project 2: Data Jobs Dashboard with DAX

![Data Jobs Dashboard Project 2](/Images/Project_2.PNG)

This project builds on the first dashboard, with a focus on DAX measures, data modeling, and interactive analysis of job posting data.

**Skills Practised**
- DAX measures and calculations
- Data modeling
- Power Query transformations
- Interactive visuals and slicers
- Dashboard layout and design

[View Project 2 Details](./Data_Jobs_v2/README.md)

## About This Repository

Each project has its own README with details about the dashboard, the techniques used, and screenshots. The projects are based on learning and practising Power BI using job posting data.
